# 规则候选收件箱

本目录用于两台电脑在每条视频结束后提交可审阅的规则候选。它不是正式规则正文，也不是自动合并队列。

## 路径与权限

- `open/`：任一剪辑电脑可新增独立候选文件；不得编辑他人候选或正式 `00–07`。
- `processed/`：只由当前决策中枢移动候选并记录裁决结果。
- `规则候选模板.md`：每条候选从此模板创建。

当前这台电脑是唯一决策中枢。它在合并前必须快进拉取、检索相关 `03`、`06`、当前 Skill 与所有相关 open 候选；裁决只能是“不写入、合并证据、新建F1、修订或升级、本条经验、REVIEW”之一。

## 提交协议

1. 视频开始前执行 `git pull --ff-only`，将 `git rev-parse HEAD` 记为规则 SHA。
2. 视频结束后，在 `open/` 新建独立候选，不改正式规则。
3. 提交前再次拉取；推送被拒绝时先拉取并解决文件级冲突，禁止强推。
4. 决策中枢完成裁决后，在同一提交中更新正式规则、候选状态与关联记录。

NAS 只镜像 Git 已确认的提交，不是候选或正式规则的反向写入源。
