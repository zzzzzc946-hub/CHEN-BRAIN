# 07｜视频复盘归档

这里保存每条**已交付或已关闭视频窗口**的结构化复盘包，作为跨视频检索的案例与证据层。

- 每条视频窗口一个以 `VR-YYYYMMDD-短标题.md` 命名的归档包；未交付窗口必须明确标示，不能伪装为已验证成片。归档包发布后不可覆盖，后续补充另建修订说明并在索引中关联。
- 每份归档必须来自已落盘的任务记录、用户反馈或已验证的交付事实；聊天中未保存的内容不得猜测补写。
- 归档只保存摘要、标签、裁决和原始日志位置；不得复制、移动或改写原片、原始 EDL、成片、逐字稿或渲染缓存。
- `07｜视频复盘索引.md` 是所有归档包的唯一检索入口。新视频只按主题、内容类型、剪辑难点和反馈类型定向读取少量相关包，不全文加载历史复盘。
- 归档包不是稳定规则。稳定判断进入03，校准证据与例外进入06；仅本条有效的经验保留在归档包。

## 双机边界

当前电脑是唯一决策中枢：可裁决归档并更新索引、03和06。另一台电脑只能新增独立候选归档到 `08｜规则候选收件箱/open/`，等待决策中枢处理；不得直接改写本目录、索引或正式规则。NAS 只接收 Git 已确认版本的单向镜像。
